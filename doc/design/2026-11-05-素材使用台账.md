## 3. 处理方式

1. 原图 512×512 → **320×320**（HighQualityBicubic，保留透明通道）。
   - 依据：页面最大显示 136px，按 2× DPR 需要 272px，320px 为最小清晰档。
   - 结果：单张从 105–304 KB 降到 50–136 KB，单页只加载 1 张，满足「单页图片总重 ≤ 600KB」。
2. 组件侧统一用 `next/image` + 显式 `width/height`（320×320）+ `priority`（首屏页头）。
3. 画框统一 `.brand-art-frame`：方形画框 + `.brand-art` 100% 填充 + `object-contain`，
   保证图形不溢出压住标题 / 徽标；环境光用 `--accent-base`，深色加强落影。
4. 全部 `alt=""` + `aria-hidden`：纯装饰，不进无障碍树。
