# 2026-10-14 技能广场前端设计与实现（aoteman-web）

> 关联：
> - 后端设计：`aoteman-platform/doc/design/2026-10-14-技能广场设计.md`（含表结构、P1/P2 边界）
> - 后端 P1 接口：`aoteman-agent` 的 `SkillController`
>   - `GET  /api/skills?userId=...`
>   - `GET  /api/skills/mine?userId=...`
>   - `POST /api/skills/{name}/install?userId=...`
>   - `DELETE /api/skills/{name}/install?userId=...`

## 1. 现状

- 数据面 `aoteman-agent` 提供技能广场 P1 接口，返回 `[{ name, description, source, installed }]`。
- 正式前端为 `aoteman-web`（Next.js 15 + React 19 + TypeScript + TailwindCSS 4 + Radix UI）。
- 前端已有登录态：`useCurrentUser()` 经 BFF `/api/auth/me` 从控制面拿到真实用户（含 `userId`）。
- 前端已有 BFF 模式：`/api/sessions` 等服务端代理转发数据面，浏览器不直连 8080。
- 聊天页 `src/app/page.tsx` 顶栏已有：身份信息、新会话、用户菜单、主题切换；左侧会话导航。

## 2. 目标

在 `aoteman-web` 聊天页顶栏新增「技能广场」入口，打开模态面板：

1. 查看广场技能目录（名称 / 描述 / 来源）；
2. 看到当前登录用户「已安装 / 未安装」状态；
3. 一键安装 / 卸载广场技能（幂等，成功后可筛看「已安装」列表）。

## 3. 设计决策

| # | 事项 | 决策 | 理由 |
| --- | --- | --- | --- |
| F1 | UI 位置 | 聊天页顶栏加「技能广场」按钮，弹出居中模态面板（Radix Dialog） | 与聊天主流程解耦；复用既有 shadcn 组件与设计 token，不新增路由页 |
| F2 | 数据通道 | 新增 BFF：`/api/skills`、`/api/skills/{name}/install`，转发数据面 | 维持「浏览器不直连数据面」的既有架构；P2 切控制面鉴权只改 BFF |
| F3 | 身份 | `useCurrentUser().userId` 传入 BFF，未登录回退 `anonymous` | 与聊天页 `identity.userId` 同源，安装关系写入同一 `user_id` |
| F4 | 状态刷新 | 安装 / 卸载成功后整体 `GET /api/skills` 刷新 | 服务端幂等，以服务端结果为唯一状态源，避免前端双份状态 |
| F5 | 体验 | 列表 / 已安装两个分段筛选 + 每卡片 busy 防重复点击 + sonner 轻提示 | 状态可预期、操作可感知 |
| F6 | 空态/失败态 | 加载骨架 / 空列表 / 接口报错三态 | 用户可理解结果 |
| F7 | 范围 | 仅「列表 + 安装 + 卸载」；**不做** ADMIN 上传/下载（P2） | 与后端 P1 边界对齐 |

## 4. 交互流程

```text
顶栏点击「技能广场」
      │
      ▼
打开 Dialog ──► 显示骨架屏 ──► GET /api/skills（BFF → 数据面）
      │
      ├─ 成功 ─► 渲染卡片列表（名称/描述/来源 + 安装|卸载按钮 + 已安装角标）
      └─ 失败 ─► 错误文案 + 「重试」
      │
      ▼
点击「安装」/「卸载」
      │
      ▼
POST/DELETE /api/skills/{name}/install（BFF → 数据面）
      │
      ├─ 成功 ─► 整体刷新列表（换按钮态 / 角标）
      └─ 失败 ─► 按钮恢复，sonner 错误提示
```

关闭：右上角 ✕ / 点击遮罩 / Esc（Radix Dialog 内建）。

## 6. 验证计划

1. `pnpm exec tsc --noEmit` / `pnpm lint` 通过。
2. 启动数据面（8080，local profile）与控制面（8081），`pnpm dev` 打开前端。
3. 顶栏点「技能广场」：面板开合正常，列表真实拉取。
4. 安装 / 卸载后卡片状态与角标即时变化；刷新面板后状态持久（MySQL `skill_installation`）。
5. 接口失败（停数据面）时展示错误态，按钮可重试。

## 7. 边界与后续

- 匿名（userId 为空）走 `anonymous`，行为与聊天页一致；P2 启用 `agent.auth.enabled` 后由 BFF 用 Cookie 解析身份、丢弃 query 直传。
- ADMIN 上传 / 下载 / 下架属 P2：届时在对象面板中按角色渲染管理按钮，调用后端待开发的 P2 接口。
